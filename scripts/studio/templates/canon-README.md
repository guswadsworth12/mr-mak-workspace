# Canon

This folder is the source of truth for the game: story, characters, world
rules, art direction, tone and core design pillars. Agents read it freely.
Agents can only change it through an approved `canon` gate that lists the
exact files, so nothing here changes without Scott's decision.

Suggested files: `pillars.md`, `art-direction.md`, `characters/`, `world/`, `glossary.md`.
